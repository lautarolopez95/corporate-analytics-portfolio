# 🏢 Corporate Analytics & Automation Portfolio

Este repositorio contiene **casos de estudio** de proyectos desarrollados en mi rol actual. 

> **Nota de Confidencialidad:** Debido a políticas empresariales (NDA), no es posible compartir el código fuente, repositorios directos, ni datos reales de la compañía. La información, métricas y capturas de pantalla han sido anonimizadas (dummy data) o abstraídas para demostrar la arquitectura, el enfoque técnico y el impacto en el negocio sin comprometer información sensible.

## 📑 Índice de Proyectos

### 1. Operaciones y Mantenimiento
*   [**LILA App & Dashboard**](./case-study-lila-app.md): Aplicación para gestión de tareas operativas en planta (Limpieza, Inspección, Lubricación y Ajustes).
*   [**Efficiency Tracking Dashboard**](./case-study-efficiency-tracking.md): Suite analítica que incluye el análisis profundo de OEE (Streamlit) y el monitoreo de indicadores de confiabilidad MTBF/MTTR (Looker Studio) a partir de una única fuente de datos.

### 2. Gestión Financiera y KPIs
*   [**Maintenance Expenses Tracker**](./case-study-maintenance-expenses.md): Dashboard para el control del presupuesto y gastos operativos de mantenimiento.
*   [**Maintenance Orders Compliance**](./case-study-maintenance-orders.md): Herramienta de visualización operativa para medir el cumplimiento de órdenes de trabajo.
*   [**SAP Tickets Resolution (OTIF)**](./case-study-sap-tickets.md): Herramienta de seguimiento para resolución de tarjetas SAP y medición del KPI OTIF (On Time In Full).

---

## 🛠️ Stack Tecnológico Común
*   **Extracción de Datos:** SAP (Exportaciones periódicas).
*   **Base de Datos / Transformación:** Google Sheets como hub de datos centralizado.
*   **Visualización:** Google Data Studio (Looker Studio) y Streamlit (Python).
*   **Captura de Datos Operativos:** AppSheet.
